# Inkly

Drogi Użytkowniku
W poniższych folderach znajdziesz
- Kod źródłowy
- Pliki do dystrybucji projektu
- Instalator do aplikacji Inkly

Obecnie projekt jest w fazie beta, mogą być błędy
Notatki są automatycznie zapisywane co 8 sekund do folderu C:\Users\<nazwa>\AppData\Roaming\Inkly\Inkly\notes.json
Planowane funkcje do wersji v1.1.0:
- Eksport notatek z poziomu przycisku w aplikacji
- Import notatek z pliku zapisu

Projekt pisany na bazie języka C++ w aplikacji MSVC 2026 Insiders
Wykorzystuje Visual C++ Redistributable (znajduje się w folderze dystrybucyjnym)
Skompilowane do instalatora za pomocą Nullsoft Scriptable Install System

Miłego używania!
